# Code of Conduct

## Our Pledge

We pledge to make participation in Tessera a respectful, inclusive, and harassment-free experience
for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but take responsibility for impact.
- Welcome questions and help others learn.
- Give feedback that is specific, kind, and useful.
- Keep discussions focused on the project and its users.

## Unacceptable Behavior

- Harassment, intimidation, discrimination, or personal attacks.
- Dismissive or hostile comments.
- Publishing private information without permission.
- Sharing secrets, credentials, or sensitive data.
- Any conduct that would be inappropriate in a professional engineering environment.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when
behavior violates this code of conduct.

## Scope

This code applies to repository discussions, issues, pull requests, documentation, project spaces,
and related communication channels.
